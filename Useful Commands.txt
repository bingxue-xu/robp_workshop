Running the arm servos!!!! : ros2 run micro_ros_agent micro_ros_agent serial --dev /dev/ttyUSB1 -v6


Servo topic : /multi_servo_cmd_sub



Message type: ros2 topic pub /multi_servo_cmd_sub --once std_msgs/Int16MultiArray "{layout: {dim: [{label: '', size: 0, stride: 0}], data_offset: 0}, data: [12000,12000,12000,12000,12000,12000,500,500,500,500,500,500]}" 

data:[servo1_desired_pos, servo2_desired_pos, ... , servo6_desired_pos, servo1_move_time, ... , servo6_move_time



servo1 = claw higher number = close
servo2 = revolute joint below claw, rotates about  axis , higher number = rotate ccl (around z axis)
servo3 = revolut joint after that, higher number = forward towards NUC
servo4 = joint after that, higher number = backwards
servo 5 = second to last joint, higher = forward
servo 6 = rotating base higher number = rotate ccl (around z axis)
